# SidelineReel — Jersey Match Confidence + Coach Review (Prototype)

Product Manager assessment for [Ajaia](https://ajaia.ai) by **Muhammad Izaan** (izaanatif@gmail.com).

- **Live prototype:** https://izaan-sudo.github.io/sidelinereel-prototype/
- **Run locally:** download `index.html` and open it in any browser (single file, no install, works offline).
- **Submission write-up:** [submission.md](submission.md)

## Core flow
1. **Tagging & routing** — confidence per clip, look-alike jersey pairs (4/14, 1/11, 12/21) computed from the roster, adjustable thresholds.
2. **Coach review** — one-tap confirm / reassign / remove for held clips; decisions update reels live.
3. **Parent reel** — only confirmed clips, safe thumbnail, "Not my kid" flag that hides the clip and returns it to the coach.

All data is simulated; player names are fictional.
